# 🎓 Campus Voice

Campus Voice is a secure anonymous complaint management system built for educational institutions. It enables students to report campus issues anonymously while allowing administrators to manage and resolve complaints efficiently.

---

## ✨ Features

- 🔐 User Registration with Email OTP Verification
- 🔑 Forgot Password using Email OTP
- 👤 Secure Login with Password Hashing
- 📝 Anonymous Complaint Submission
- 📷 Image Upload with Complaints
- 📄 My Complaints Section
- 🗑 Delete Pending Complaints
- 👍 One Support per User for Each Complaint
- 🛠 Admin Dashboard
- 🔍 Search and Filter Complaints
- 📊 Complaint Statistics Dashboard
- 🔄 Complaint Status Management
- 🔒 Environment Variables using .env

## 🚀 How to Run

1. Clone the repository

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the application

```bash
python app.py
```

4. Open

```
http://127.0.0.1:5000
```
